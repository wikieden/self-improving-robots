闭环与奖励

AR01 · 读一篇"机器人自改进"论文时，先问哪三个问题？三个词 Agentic、WAM、RSI 各管闭环的哪一部分？

来源：第 1 章 · 加入 2026-11-20 · 复习记录：

答案

闭环：\(\theta_{k+1} = \mathrm{Update}(\theta_k, \mathrm{Filter}(\mathrm{Generate}(\theta_k)))\)，即生成 → 打分 → 更新。

三问：经验从哪来（真机 / 仿真 / 想象）；分数从哪来（0/1、进度、价值、VLM 判官）；被更新的是什么（VLA 权重、残差、规划器、技能库、世界模型）。

Agentic 管"谁来驱动闭环"（选练什么、重置、判成败）；WAM 管"在想象里跑闭环"；RSI 问"闭环能不能一轮比一轮强"。

口诀：生成打分再更新，经验分数改了谁。

AR02 · VLA 只靠模仿学习，为什么学不会纠错？每步偏离概率 0.02、50 步，至少偏离一次的概率是多少？

来源：第 1 章 第二步 · 加入 2026-11-20 · 复习记录：

答案

暴露偏差：示范只覆盖专家走过的状态。机器人一旦偏离，就到了示范里没有的状态，不会纠正，误差越积越大（RISE 引言 L84–L89）。

整条不偏的概率是 \((1-q)^T = 0.98^{50} \approx 0.364\)，所以至少偏一次约 63.6%。

真机 RL 的四个难点：贵、要人重置、要人判成败、有安全风险。

口诀：模仿不会自纠错。

AR03 · 机器人 RL 的奖励有哪四种来源？进度奖励 \(r_t = g(o_t) - g(o_{t+1})\) 里 \(g\) 是什么？

来源：第 1 章 第三步 · 加入 2026-11-20 · 复习记录：

答案

四种：0/1 结果奖励（SimpleVLA-RL）；steps-to-go 步数预测（Self-Improving EFM，同时当稠密奖励和成功检测器）；价值模型 + 优势（π*0.6 RECAP）；混合稠密奖励（IG-RFT，轨迹级 + 子任务级）。

\(g(o_t)\) 是模型在观察 \(o_t\) 上预测的"离完成还差几步"。例：\(g\) = 10, 8, 8, 5 → \(r\) = 2, 0, 3（示意形式，第 8 章核对原文）。

优势 \(A = Q - V\)：比平常好多少。

口诀：稀疏奖励变稠密。

优化方式

AR04 · 写出 AWR 的样本权重公式；\(A = +1, 0, -1\)、\(\beta = 1\) 时权重各是多少？"优势条件"又是怎么做的？

来源：第 1 章 第四步 · 加入 2026-11-20 · 复习记录：

答案

\(w = \exp(A/\beta)\)，\(\beta\) 是温度。权重是 2.718、1、0.368，好样本的权重是差样本的 7.4 倍。

优势条件（RECAP、RISE）：训练时把 \(I = \mathbb{1}[A > 0]\) 当作输入条件，推理时固定 \(I = 1\)，只生成"比平常好"的动作。

两者都是"保留监督学习的训练方式，只把优势当权重或条件"。

口诀：梯度变加权。

AR05 · PLD 的三个阶段各做什么？为什么叫"大模型稳着学，小模块去探路"？

来源：第 1 章 第四步 · 加入 2026-11-20 · 复习记录：

答案

PLD = Probe, Learn, Distill（探测 / 学习 / 蒸馏），pld-residual-rl L20–L28： 1. 冻结 VLA，用 off-policy RL 训练小残差 \(a = a_{\text{base}} + a_{\text{res}}\)，在基础策略会失败的地方接管（探测失败区）； 2. 收集数据时让残差介入偏向基础策略常去的状态（分布对齐），录下纠正行为； 3. 用 SFT 把这些数据蒸馏回大模型。LIBERO 上约 99%。

探索交给小模块，大模型只吸收筛过的数据，训练稳定，不洗掉预训练学到的能力。FIND 也用"冻结 π0.5 + 残差 RL"。

口诀：大模型稳小模块探。

WAM 与 Agentic

AR06 · Motus2 说 WAM 一套权重暴露哪三个接口？各对应 RL 里的什么角色？

来源：第 1 章 第五步 · 加入 2026-11-20 · 复习记录：

答案

策略（world–action model，提出候选动作块）→ actor；模拟器（action-conditioned world model，预测视觉后果）→ 环境模型；评估器（value model，给预测结果打分）→ critic / 奖励。三者串起来就是 model-based RL 回路（motus2 L25–L27）。

代表：RISE = 可控动力学 + 进度价值模型，在想象里算优势。

口诀：想象里练。

AR07 · 在世界模型里练，策略会怎样"钻想象的空子"？WAV、EVO-WAM、R²-WAM、MERL 各用什么办法防？

来源：第 1 章 第五步 · 加入 2026-11-20 · 复习记录：

答案

想象出的画面看起来像成功，但不一定忠实反映输入的动作；策略会专挑世界模型预测错的地方得高分。

  • WAV：拆成"状态合理吗 + 动作能到达吗"两件事分别验证，靠两种不对称（无动作视频多；动作相关特征维度低），再加逆模型循环一致性。
  • EVO-WAM：VLM 挑完成任务的前缀 + IDM 核对视频–动作一致，再自训（Cosmos3 26.9% → 68.0%）。
  • R²-WAM：先修（让想象服从动作），再拒（对想象进度不如示范的样本做负向微调）。
  • MERL：按可信度控制想象数据比例和时域。

口诀：想象要验。

AR08 · Agentic 和 RL 有哪两种结合方式？各举一个代表和关键数字。

来源：第 1 章 第六步 · 加入 2026-11-20 · 复习记录：

答案

A. Agent 当 RL 的"操作员"，把人从闭环里拿掉：FIND（VLM 按场景和近期成功率选任务、用前后观察判成败，55% → 71.9%，6 小时 456 个 episode、30 次救场、无人工奖励标签）；RoboClaw（EAP 正向 + 逆向配对自重置，人力时间 −53.7%）。

B. 用 RL 训练规划器本身：AgenticRoboRL（SFT + 多轮 RL，只给结束时奖励、组内相对优势、执行层不动；9B 规划器 18.1% → 71.0%，接近 Codex + 记忆的 72.1%）。

组内相对优势 \(A_i = r_i - \bar r\)；全成功或全失败的组优势全为 0，学不到东西。

口诀：agent 管闭环，规划器也能练。

RSI 层级

AR09 · 递归自改进的四个层级是什么？为什么说"执行上自主 ≠ 改进上自主"？

来源：第 1 章 第七步 · 加入 2026-11-20 · 复习记录：

答案

L1 episode 内纠正（SC-VLA、Inner Monologue）；L2 持久改进，写进权重或技能库（RECAP、PLD、RoboClaw）；L3 版本继承、多轮迭代（Self-Improving EFM、EVO-WAM）；L4 改进流程本身变好（具身几乎没有；软件 agent 有 Darwin Gödel Machine）。

机器人能自己干活、自己采数据，只说明执行自主；只有"产生改进的流程"本身在变好，才算改进自主。有技能库也不等于 RSI。

口诀：改进流程是第四层。

AR10 · 自改进闭环什么时候往上走、什么时候往下掉？（筛选器的误收率 fp、漏收率 fn）

来源：第 1 章 动画 · 加入 2026-11-20 · 复习记录：

答案

收下样本的成功率 precision \(= \dfrac{p(1-\text{fn})}{p(1-\text{fn}) + (1-p)\,\text{fp}}\)，更新 \(p \leftarrow (1-\eta)p + \eta \cdot \text{precision}\)。

precision > p ⇔ fp < 1 − fn：筛选器比瞎猜好就往上走，越准越快；fp > 1 − fn 就往下掉（奖励黑客的玩具版）；不筛选时 precision = p，原地不动。

这就是"验证比生成容易"为什么是闭环的前提。

口诀：验证容易闭环升。
