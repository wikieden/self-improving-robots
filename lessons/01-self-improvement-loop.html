讲解

第一步：一个闭环，三个问题（2026-11-20）

类比：学生刷题。 做一套题 → 对答案，只把做对的题（或改对的错题）抄进笔记 → 照着笔记复习。下一轮再做题时，人已经变强，做出来的题也更好。机器人的 RL 也是这个循环。

\[\theta_{k+1} = \mathrm{Update}\big(\theta_k,\ \mathrm{Filter}(\mathrm{Generate}(\theta_k))\big)\]
  • \(\theta_k\)（读作"西塔 k"）：第 \(k\) 轮的模型参数。被更新的不一定是 VLA 权重，也可以是技能库、规划器、世界模型。
  • \(\mathrm{Generate}\)：用当前模型产生经验（真机、仿真或想象里的一次次尝试）。
  • \(\mathrm{Filter}\)：打分筛选（成功 / 失败、进度高 / 低）。
  • \(\mathrm{Update}\)：用筛过的经验更新自己。

例子（数是编的）：机器人试了 10 次，成功 4 次。只留这 4 条轨迹做 BC，新策略更像"成功的那 4 次"。下一轮可能成功 6 次，再留 6 条……

读任何一篇论文，先问这三个问题：

问题 可能的答案
经验从哪来 真机、仿真、世界模型的想象
分数从哪来 0/1 成功、进度模型、价值模型、VLM 判官
被更新的是什么 VLA 权重、残差小网络、规划器、技能库、世界模型

三个词各管闭环的一部分：Agentic 管"谁来驱动闭环"（选练什么、重置场景、判成败）；WAM 管"在想象里跑闭环"；RSI 问"闭环能不能一轮比一轮强"。

一句话：机器人 RL = 生成 → 打分 → 更新；先问经验、分数、被更新的东西各是什么。

第二步：VLA 为什么需要 RL（2026-11-20）

类比：只看过老司机录像的新手。 只要车一偏离录像里的路线，他就没见过这种画面，越开越偏。

RISE 引言说，IL 受示范的质量和覆盖范围限制，还有暴露偏差（exposure bias）：机器人一旦稍微偏离专家的分布，就没有纠正能力，误差会越积越大（rise-2602.11075.txt L84–L89）。原文是这样说的：

"once the robot drifts slightly off the expert's manifold, it lacks the recovery skills"

用数字感受误差累积：假设每一步有 \(q\) 的概率偏离示范分布，一条轨迹有 \(T\) 步，那么整条轨迹都没偏离的概率是：

\[P(\text{整条都不偏}) = (1-q)^T\]

例子（数是编的）：\(q = 0.02\)、\(T = 50\)，算出 \(0.98^{50} \approx 0.364\)。也就是说，约 63.6% 的轨迹至少偏离一次。偏离以后的状态示范里没有，只有靠机器人自己试错，才学得到怎么纠正回来。

RL 恰好补上这个缺口，但在真机上做 RL 有四个难点：贵、要人重置场景、要人判成败、有安全风险（world-vla-loop-2602.06508.txt L49–L50；find-agentic-rl-2609.32069.txt 引言）。后面几步的方法，都是在想办法把这四件事从人手里拿走。

一句话：IL 学不会纠错，RL 能学会；真机 RL 难在贵、重置、判成败和安全这四件事。

第三步：奖励从稀疏走向稠密（2026-11-20）

类比：打分。 考试只给"及格 / 不及格"（稀疏），学生不知道错在哪；老师逐题批改（稠密），学生就知道哪一步扣了分。

做法 代表 原文位置 要点
0/1 结果奖励 SimpleVLA-RL simplevla-rl L335 成功给 1、失败给 0；需要仿真器能判断成败
步数预测（steps-to-go） Self-Improving EFM self-improving-efm L20–L22 SFT 时顺带训练"离完成还差几步"，这一个头同时给出稠密奖励和成功检测器
价值模型 + 优势 π*0.6 RECAP pistar06-recap L26、L67 价值模型算优势，按优势给策略打"这次是改进"的标签
混合稠密奖励 IG-RFT ig-rft L32 轨迹级奖励加子任务级奖励

进度奖励的思路（示意，论文的具体形式到第 8 章再核对）：设 \(g(o_t)\) 是模型在观察 \(o_t\) 上预测的"还差几步"，每一步的奖励取"差的步数减少了多少"：

\[r_t = g(o_t) - g(o_{t+1})\]

例子（数是编的）：\(g\) 依次是 10、8、8、5，奖励依次是 2、0、3。中间那步原地踏步，得 0 分；最后那步进展最大，得 3 分。\(g\) 降到 0 附近，就可以当作"成功"。

优势（advantage）：这一步比"平常水平"好多少。

\[A(s,a) = Q(s,a) - V(s)\]

\(Q\) 是在状态 \(s\) 做动作 \(a\) 之后的预期回报，\(V\) 是在 \(s\) 的平均预期回报。例如 \(Q = 0.8\)、\(V = 0.5\)，算出 \(A = +0.3\)，说明这个动作比平常好。

一句话：奖励从 0/1 走向进度和优势，机器人才知道哪一步做对了。

第四步：优化方式：把 RL 变回加权的监督学习（2026-11-20）

类比：改错本加星号。 不重写教材，只给每道题标上"重点"或"少看"，复习时照着权重来。

VLA 的动作头大多是 flow matching 或扩散模型，动作的对数概率不好算。所以主流做法是保留监督学习的训练方式，只把优势当成权重或条件：

AWR（IG-RFT 的 IG-AWR 就是它的变体，ig-rft L29）：每条样本的权重是

\[w = \exp(A / \beta)\]

\(\beta\)（读作"贝塔"）是温度，越小越偏心好样本。例子：\(A\) 分别是 \(+1, 0, -1\)，取 \(\beta = 1\)，算出权重 2.718、1、0.368。好样本的权重是差样本的 7.4 倍。

优势条件（RECAP、RISE）：训练时把指示量 \(I = \mathbb{1}[A > 0]\) 当成一个输入条件（\(\mathbb{1}[\cdot]\) 读作"指示函数"，括号里成立取 1，否则取 0）；推理时固定 \(I = 1\)，只生成"比平常好"的动作。

残差 RL + 蒸馏（PLD，pld-residual-rl L20–L28）：冻结大 VLA，只训练一个小残差网络 \(\pi_{\text{res}}\)：

\[a = a_{\text{base}} + a_{\text{res}}\]

做法分三步： 1. 残差用 off-policy RL 训练，在基础策略会失败的状态里接管（探测失败区）； 2. 收集的数据偏向基础策略常去的状态； 3. 最后用 SFT 把这些数据蒸馏回大模型。

PLD 在 LIBERO 上做到约 99%。FIND 也用"冻结 π0.5 + 残差 off-policy RL"这套组合。

一句话：大模型稳着学，小模块去探路，最后把探到的经验蒸馏回大模型。

第五步：WAM 与 RL：在想象里练（2026-11-20）

类比：飞行模拟器。 在模拟器里摔一万次都不花钱，但模拟器做得不像，练出来的技巧到真飞机上就不灵。

WAM 一身三用（Motus2，motus2 L25–L27）：同一套权重暴露三个接口。

接口 作用 对应 RL 里的角色
策略（world–action model） 提出候选动作块 actor
模拟器（action-conditioned world model） 预测这些动作的视觉后果 环境模型
评估器（value model） 给预测结果打分 critic / 奖励

三者串起来，本身就是一个基于模型的 RL（model-based RL）回路。

三篇代表： - RISE（rise L64–L79）：组合式世界模型 = 可控动力学模型（预测多视角未来）+ 进度价值模型（打分）。在想象里算优势，再做优势条件训练。三个真机任务的成功率分别提升约 35%、45%、35%（绝对值）。 - World-VLA-Loop（world-vla-loop L48–L70）：世界模型训练时专门混入"差一点就成功"的轨迹（SANS 数据集），并在扩散隐变量上联合预测画面和 0/1 奖励。策略和世界模型交替更新，原文叫 co-evolving（共同进化）。 - MERL（merl L19–L27）：按模拟器的可信度，控制想象数据占多大比例、往前想象多远。

核心风险：策略钻想象的空子。 想象出来的画面"看起来像成功"，但不一定忠实反映输入的动作。策略会学会专挑世界模型预测错的地方得高分。几种对策：

对策 代表 做法 原文
自我验证 WAV 把预测拆成"状态合理吗""动作能到达吗"两件事分别验证。理由是两种不对称：没有动作标签的视频多得多；跟动作相关的特征维度低得多 world-action-verifier L19–L38
用 IDM 核对 EVO-WAM VLM 挑出完成任务的前缀，IDM 核对视频和动作是否一致，再用这些自生成数据自训。Cosmos3 在 7 个没见过的 RoboTwin 任务上从 26.9% 提到 68.0% evo-wam L27–L36
先修后拒 R²-WAM 先让想象服从动作，再对想象中进度不如示范的样本做负向微调。RoboTwin 2.0 上平均 93.8% r2-wam L24–L33
可信度门控 MERL 模拟器越不可信，想象数据用得越少、想象的时域越短 merl L23–L26

一句话：WAM 让 RL 搬进想象里做，代价是要防策略钻想象的空子。

第六步：Agentic 与 RL 的两种结合（2026-11-20）

类比：教练和学员。 第一种是请个教练安排训练（agent 管闭环）；第二种是把教练本人也送去培训（RL 训练规划器）。

A. Agent 当 RL 的"操作员"：把人从闭环里拿掉

  • FIND（find-agentic-rl L6–L34）：VLM agent 看当前场景，决定下一步练什么，优先练近期成功率低的任务；用执行前后的成对观察判断成败。人工评估的成功率从 55% 提到 71.9%。一次 6 小时跑了 456 个 episode，只需要 30 次人工救场，没有人工奖励标签。
  • RoboClaw（roboclaw L24–L46）：用纠缠动作对 EAP 把"正向操作"和"逆向复原"配成一对，场景能自己重置；采数据和部署共用同一个 VLM agent。长程任务成功率提升 25%，人力时间减少 53.7%。
  • Agentic-VLA（agentic-vla-online 摘要）：根据当前能力动态生成奖励函数，把任务拆成子目标，形成课程学习。

"挑弱项练"的打分（示意，规则是编的；FIND 的具体规则到第 9 章核对）：让任务 \(i\) 被选中的概率正比于 \(1 - s_i\)，\(s_i\) 是近期成功率。

任务 近期成功率 \(s_i\) \(1-s_i\) 被选概率
擦桌子 0.9 0.1 0.1 / 1.4 ≈ 0.07
叠毛巾 0.5 0.5 0.5 / 1.4 ≈ 0.36
插插头 0.2 0.8 0.8 / 1.4 ≈ 0.57

B. 用 RL 训练规划器本身

AgenticRoboRL（agenticroborl L45、L114–L124）把 coding agent 的训练配方搬到机器人规划器上： - 先在成功轨迹上做 SFT，再做多轮 RL； - 执行层（VLA 技能或控制代码）固定不动，只训练规划器； - 只在任务结束时给奖励，不用学出来的 critic（L301），优势按组内相对比较计算。

结果：在 LIBERO-PRO 上，9B 规划器 SFT 后从 18.1% 提到 65.1%，RL 后到 71.0%，接近 Codex（GPT-5.5）加外部记忆的 72.1%。

组内相对优势：同一个任务试 \(G\) 次，第 \(i\) 次的优势取

\[A_i = r_i - \bar r\]

\(\bar r\)（读作"r 拔"）是这一组的平均奖励。例子（数是编的）：6 次尝试的奖励是 1、0、0、1、0、0，\(\bar r = 1/3\)。成功的两次优势是 \(+2/3\)，失败的四次是 \(-1/3\)。如果 6 次全成功或全失败，优势全是 0，这组就学不到东西。

一句话：agent 可以替人管闭环，规划器本身也可以用 RL 训练。

第七步：RSI：把上面这些放进四个层级（2026-11-20）

类比：学生的四种进步。 1. 这道题做错了，马上改对（当场纠正）； 2. 把错题记进本子，下次不再错（持久改进）； 3. 拿今年的笔记当明年的起点，一年比一年好（版本继承）； 4. 连"怎么记笔记、怎么复习"的方法本身都在进化（元层改进）。

层级 含义 例子
L1 episode 内纠正 一次任务里看反馈重试 SC-VLA、Inner Monologue
L2 持久改进 经验写进权重或技能库，下次还在 RECAP、PLD、RoboClaw
L3 版本继承 改进后的模型当下一轮的起点，多轮迭代 Self-Improving EFM、EVO-WAM
L4 改进流程本身变好 元层改进 具身方向几乎还没有；软件 agent 有 Darwin Gödel Machine

（四个层级来自 2026-10 的具身 RSI 综述，preprints.org 202610.2080，全文待读核对。）

两条原理：

  1. 验证比生成容易，这是闭环不会越练越差的前提。例子：STaR 只保留答案正确的推理（star L174），WAV 用两种不对称，EVO-WAM 用 IDM 核对。动画里能看到：只要筛选器比瞎猜好，闭环就往上走；筛选器比瞎猜还差，闭环就往下掉。
  2. 执行上自主 ≠ 改进上自主（综述的提醒）。机器人能自己干活、自己采数据，不等于改进流程在变好；有技能库，也不等于在做递归自改进。

一句话：RL 是 L2、L3 的发动机；具身方向还没做出 L4。

动画演示：自改进闭环：筛选器有多准，决定闭环往哪走

可交互版：animations/01-self-improvement-loop.html。滑块"误收率"是筛选器把失败当成成功收下的概率。

怎么看： 1. 每轮分三拍：生成 24 次尝试（绿 = 真成功，红 = 真失败）→ 筛选器打圈收下 → 用收下的样本更新成功率（第一步）。 2. 右边两条曲线：紫线是"有筛选"，灰线是"不筛选、全收"。灰线基本不动，说明只是自己学自己，学不到新东西（第一步、第七步）。 3. 把误收率拖到 0.5：紫线还在涨，只是变慢。拖到 0.95：收下的样本里失败比成功还多，紫线往下掉。这就是奖励黑客和想象被钻空子的玩具版（第五步、第七步）。

数学原理

  • 误差累积：每步独立以 \(q\) 的概率偏离，\(T\) 步都不偏的概率是 \((1-q)^T\)，随 \(T\) 指数下降。
  • 优势：\(A = Q - V\)，以平均水平为基线，只看"比平常好多少"，能降低方差。
  • AWR：在"新策略不能离旧策略太远"的约束下，最优策略正比于 \(\pi_{\text{old}}(a|s)\exp(A/\beta)\)。把它投影回参数化策略，就是按 \(\exp(A/\beta)\) 加权的回归。
  • 组内相对基线：用同一组尝试的平均奖励当基线，省掉 critic。

关键几行：

def expected_loop(p0, fp, fn=0.1, eta=0.5, rounds=10):
    p, curve = p0, [p0]
    for _ in range(rounds):
        keep_good = p * (1 - fn)            # 真成功被收下的比例
        keep_bad = (1 - p) * fp             # 真失败被误收的比例
        precision = keep_good / (keep_good + keep_bad)  # 收下的里面真成功占多少
        p = (1 - eta) * p + eta * precision  # 朝"收下样本的成功率"学一半
        curve.append(p)
    return curve

代码里才看得到的 2 件事： 1. 动画里每一拍是真随机抽样，曲线会抖；代码里用的是期望值，曲线是平滑的。两者趋势一致。 2. 闭环上升的条件是 precision > p。化简后等价于 fp < 1 - fn，也就是误收率低于"真成功被收下的概率"。这就是"筛选器比瞎猜好"的精确含义。

自己改一改（不影响练习答案）： - 把 fn（漏收率）调到 0.5，看要多低的 fp 闭环才会涨。 - 把 eta 调到 0.1 和 0.9，看收敛快慢的区别。 - 把 p0 调到 0.01，看起点很差时闭环要多少轮才起得来（冷启动问题，第 2 章细讲）。
